# Grace Models — обновление 2.4.1

С главной страницы полностью убран блок с двумя большими фотографиями «Девушки / модели», «Парни / модели», текстом «Лица, которые запоминают», круглой кнопкой каталога и нижней строкой подписей. Блок удален из разметки и больше не занимает место на странице.

В настройках кабинета убраны прежние поля двух фотографий этого блока. Логотип, новости, каталог моделей и отдельное фото «О нас» редактируются как прежде. Анкеты, заявки, изображения моделей и база данных сохраняются.

## Для уже установленной версии 2.4

1. Сохраните резервную копию сайта.
2. Распакуйте `grace-models-php-update-v2.4.1.zip` в папку с существующим `index.php`, сохраняя пути и заменяя файлы.
3. Обновите главную страницу и кабинет с перезагрузкой файлов: Ctrl+F5 или Cmd+Shift+R.

Это небольшой архив для версии 2.4. В нем находятся измененные JS-файлы, `app/bootstrap.php`, информация о сборке и эта инструкция. Рабочая конфигурация, пароль, база и загруженные фотографии в архив не включены. Изменения базы данных не требуются.

Для новой установки используйте полный `grace-models-php.zip`. Для обновления с версий до 2.4 сначала установите обновление 2.4.
