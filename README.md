# Grace Models — сайт модельного агентства

Публичный сайт с каталогом моделей и отдельной панелью управления. В первой версии используются демонстрационные анкеты, изображения и контакты: их можно заменить в панели агентства.

## Скачать сайт

**[Скачать полный архив grace-models-site.zip](grace-models-site.zip?raw=true)** — исходники, фотографии, готовая серверная сборка, схема базы данных и демонстрационные данные. Архив находится в корне репозитория и скачивается одним файлом.

**Code → Download ZIP** скачивает исходники текущей ветки. Для размещения используйте инструкцию [START_HERE_RU.md](START_HERE_RU.md).

## Возможности

- Каталог с поиском и фильтрами по полу, категории, росту, параметрам фигуры, волосам, глазам и размеру обуви.
- Индивидуальные страницы моделей, фотографии и избранные анкеты.
- Русский и английский интерфейс.
- Формы «Стать моделью» и бронирования; личные вложения доступны администратору.
- Редактор анкет и фотогалерей, обложки, черновики и публикация.
- Заявки со статусами, внутренними заметками и выгрузкой CSV.
- Журнал, контакты, тексты и оформление главной страницы.
- Вход администратора по логину и паролю с сохранением сессии между посещениями.

## Размещение

Серверная часть рассчитана на **Cloudflare Workers**, база — **Cloudflare D1**, файлы — **Cloudflare R2**. Для обычного PHP-хостинга потребуется адаптация серверной части.

Полная инструкция по переносу и восстановлению данных: [START_HERE_RU.md](START_HERE_RU.md). Пример настроек: [wrangler.example.jsonc](wrangler.example.jsonc).

Для сборки и проверок требуется Node.js 24+; установка дополнительных библиотек для этих двух команд не нужна:

```sh
npm test
npm run build
```

Пароль администратора и служебные ключи задаются в окружении сервера и не включены в репозиторий или архив. Активные сессии устройств также не экспортируются. При переносе установите пароль командой `node scripts/set-admin-password.mjs` после настройки своего Cloudflare.

## Структура

| Каталог | Содержимое |
| --- | --- |
| `public/` | Страницы, стили, браузерный код и фотографии |
| `worker/` | Сервер, авторизация, заявки и работа с данными |
| `drizzle/` | Миграции базы |
| `backup/` | Демонстрационные данные и SQL для восстановления |
| `scripts/` | Сборка и перенос на свой аккаунт |
| `tests/` | Автоматические проверки |

Источники демонстрационных фотографий: [public/images/assets.json](public/images/assets.json). Имена и параметры демонстрационных моделей вымышлены.
