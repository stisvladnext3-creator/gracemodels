# Grace Models — сайт для обычного PHP-хостинга

Сайт модельного агентства **Grace Models** с каталогом, анкетами и отдельной панелью администратора. Работает на PHP 8.1+ с MySQL/MariaDB или SQLite. Cloudflare, Node.js и Composer на хостинге не требуются.

**[Скачать готовый PHP-архив](https://raw.githubusercontent.com/stisvladnext3-creator/gracemodels/main/grace-models-php.zip)**

В архиве уже лежат файлы для загрузки в `public_html` / `www`. Сборку на хостинге запускать не нужно.

**[Скачать обновление 2.2.1 для установленной PHP-версии](https://raw.githubusercontent.com/stisvladnext3-creator/gracemodels/main/grace-models-php-update-v2.2.1.zip)** · [Что изменилось и как загрузить](UPDATE_PHP_V2_2.md).

## Установка

1. Распакуйте содержимое ZIP в корень сайта вместе со скрытым `.htaccess`.
2. Откройте `/install.php` на своем домене.
3. В файловом менеджере хостинга прочитайте созданный `install-key.php` и скопируйте код в установщик.
4. Оставьте название **Grace Models** и логин **gracemodels**, задайте выбранный пароль и подключите SQLite либо MySQL из панели хостинга.
5. Завершите установку и сохраните отдельный адрес панели, который появится после установки.

Полная инструкция: **[INSTALL_PHP.md](INSTALL_PHP.md)**.

## Возможности

- Каталог с поиском и фильтрами, страницы моделей, фотографии и избранное.
- Поиск по имени и фамилии; отдельные фильтры чашки бюста и обхвата груди, роста, талии, бедер, глаз, волос и обуви.
- Русская и английская версии.
- Анкета кандидата с 14 лет: контакты, возраст числом, параметры, внешность, файлообменник и фотографии; формы бронирования и приватные вложения заявок.
- Редактор анкет, обложки, порядок фотографий, черновики и публикация.
- Статусы заявок, заметки команды, экспорт CSV и резервная выгрузка JSON.
- Новости, контакты, тексты и фотографии главного экрана.
- Переключатель приёма анкет «Стать моделью» в настройках.
- Согласие на обработку данных с реквизитами агентства, фиксация даты и редакции в заявках; управление cookie.
- Вход по логину и паролю, сессии в базе с продлением между посещениями.
- Поддержка входа после перехода с HTTP на HTTPS без отключения проверки сторонних запросов.

Приложение не завершает вход по таймеру неактивности. Повторный вход потребуется после выхода, очистки cookies или изменения пароля. Рабочие пароли, ключи, конфигурация хостинга и активные сессии в репозиторий не включены.

## Для разработчика

- `index.php`, `app/` — PHP-сервер и установщик.
- `public/` — общие HTML-шаблоны, стили, JavaScript и изображения.
- `scripts/package-php.py` — сборка готового PHP-ZIP.
- `tests/php_smoke.py` — HTTP-проверки на Apache с SQLite и MySQL.
- `nginx.example.conf` — пример для Nginx без Apache.
- `worker/`, `drizzle/` и прежние Node-проверки сохранены как исходники предыдущей Cloudflare-версии. В PHP-архив они не входят.

Демонстрационные анкеты и фотографии можно заменить через панель. Источники изображений перечислены в `public/images/assets.json`. Текст согласия и реквизиты оператора предоставлены агентством; они находятся в `public/privacy.html`, сведения о cookie — в `public/cookies.html`.
