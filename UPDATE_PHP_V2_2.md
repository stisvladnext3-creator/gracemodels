# Grace Models — обновление 2.2.1

## Как загрузить на NIC.ru

1. Сохраните резервную копию файлов и базы в панели хостинга.
2. Распакуйте `grace-models-php-update-v2.2.1.zip` и загрузите его содержимое с заменой в существующую папку PHP-сайта — туда, где находятся `index.php` и ваш `config.php`. Структуру папок сохраните.
3. Откройте сайт и кабинет по HTTPS, затем перезагрузите страницу с обновлением файлов (Ctrl+F5 или Cmd+Shift+R).
4. Новые поля заявок добавятся в MySQL или SQLite автоматически. Для пользователя MySQL требуется право `ALTER` на таблицы сайта.

В ZIP обновления нет `config.php`, паролей, базы, активных сессий и загруженных фотографий. Текущие анкеты, заявки, адрес кабинета и пароль сохраняются. Архив включает и предыдущие правки 2.1, поэтому подходит для установки поверх PHP-версий 2.0, 2.1 и 2.2. Отдельный импорт SQL и повторная установка не требуются.

## Вход после подключения SSL

Исправлена ошибка «Недопустимый источник запроса» при переходе с HTTP на HTTPS на том же домене. После успешного входа сохраненный адрес в `config.php` автоматически обновляется на HTTPS, если папка сайта доступна PHP для записи. Остальные настройки остаются прежними. Вход использует защищенную cookie, в том числе при работе через сервер хостинга, который завершает SSL перед PHP.

Для немедленного исправления без ожидания загрузки обновления откройте свой `config.php` в файловом менеджере NIC.ru и укажите в `site_url` точный текущий HTTPS-адрес сайта без завершающего слеша. Например, для домена `example.ru`: `'site_url' => 'https://example.ru'`. Вариант с `www` должен совпадать с адресом открытого кабинета. Рабочие реквизиты из этого файла в GitHub или чат загружать не нужно.

Проверка сторонних доменов сохраняется: обновление разрешает переход протокола на том же домене, а запросы с посторонних адресов и явные запросы между сайтами блокируются.

## Анкета «Стать моделью»

Принимаются кандидаты от 14 лет, включая 14, 15, 16 и 17 лет.

Обязательные поля отмечены звездочкой: ФИО, город, ник в Телеграм, возраст числом, телефон, электронная почта. Дата рождения в новой форме не запрашивается. Для отправки также обязательно отдельное подтверждение согласия на обработку персональных данных; отметка заранее не выбрана.

Необязательные поля: рост, обхват груди, чашка бюста, талия, бедра, обувь, цвет волос, цвет глаз, ссылка на файлообменник, сообщение и фотографии. Можно выбрать или перетащить до трех фотографий, до 3 МБ каждая. Поддерживаются JPG/JPEG, PNG и WebP.

Все поля сохраняются в приватной заявке, видны в кабинете и включаются в CSV. При подготовке анкеты модели из заявки переносятся введенные параметры. Новые поля в старых заявках остаются пустыми, недостающие значения не придумываются. Обязательность полей, возраст, согласие, типы и размер файлов проверяются на сервере.

## Названия и язык

«Основной борд» заменен на «Модели» в меню, каталоге и кабинете. В русской версии переведены мелкие подписи на главной, фото, в разделах и на странице входа. Фирменное название Grace Models и переключение языков сохранены; при выборе английского интерфейс работает на английском.
