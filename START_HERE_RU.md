# Grace Models — установка на обычный PHP-хостинг

Это самостоятельная PHP-версия сайта с собственной админской панелью. Для работы не нужны Cloudflare, Node.js, Composer или сборка на хостинге.

## Требования

- PHP 8.1 или новее; рекомендуется PHP 8.3/8.4.
- Apache 2.4 или LiteSpeed с поддержкой `.htaccess` и `mod_rewrite`.
- PDO с MySQL/MariaDB **или** PDO SQLite. Расширение Fileinfo для загрузки фотографий.
- HTTPS на вашем домене.
- Папка для данных, доступная PHP для записи и расположенная вне `public_html` / `www`.

Версию PHP и расширения обычно можно выбрать в панели хостинга. Если доступна SQLite, отдельную базу MySQL создавать не нужно.

## Установка

1. Скачайте **grace-models-php.zip** и загрузите его на хостинг.
2. Распакуйте **содержимое архива в корень сайта** — `public_html`, `www` или аналогичную папку вашего домена. В ней должны оказаться `index.php`, `install.php`, `.htaccess`, папки `app` и `public`. Обязательно перенесите скрытый файл `.htaccess`.
3. Откройте `https://ваш-домен.ru/install.php`. Страница проверит требования и создаст файл `install-key.php`.
4. В файловом менеджере хостинга откройте **install-key.php** и скопируйте значение между кавычками после `return`. Вставьте его в поле «Код установки» на странице. Код не выдается через сайт; он подтверждает ваш доступ к файлам хостинга.
5. Название агентства уже установлено: **Grace Models**. Логин по умолчанию — **gracemodels**. Введите пароль, который вы ранее выбрали, и повторите его. Пароль не записан в скачанный архив или GitHub.
6. Выберите базу:
   - **SQLite:** данные хранятся в отдельном файле; дополнительные реквизиты не нужны.
   - **MySQL/MariaDB:** создайте базу и пользователя в панели хостинга, затем введите имя базы, пользователя, пароль и адрес сервера. Обычный адрес — `localhost`, порт — `3306`. У пользователя должны быть права создавать таблицы и изменять данные.
7. Проверьте путь к папке данных. Установщик предлагает папку рядом с корнем сайта. Если ее нельзя создать автоматически, создайте папку вне `public_html` в файловом менеджере и укажите полный путь. Папка должна быть разрешена настройкой PHP `open_basedir` и доступна PHP для записи.
8. Оставьте отметку «Добавить демонстрационные анкеты и статьи», если хотите начать с готового примера каталога. Снимите ее для пустого каталога.
9. Нажмите **«Установить Grace Models»**. После успешной установки откроется вход в панель по отдельному случайному адресу вида `/s/…`. **Сохраните этот адрес в закладках.** Он также записан в `config.php` в поле `admin_path`.

Повторная установка блокируется автоматически. Исходные демонстрационные анкеты можно изменить или удалить в панели. После удаления они не восстанавливаются.

## Работа с сайтом

Обновление установленной PHP-версии описано в `UPDATE_PHP_V2_3.md`.

В панели доступны модели, фотографии, обложки, порядок анкет, черновики и публикация, основной борд, новые лица, заявки, статусы и заметки, новости, контакты и тексты RU/EN.

Заявки сохраняются в базе, появляются в панели и отправляются целиком с фотографиями на почту агентства. По умолчанию используется почта хостинга; настройка SMTP и повторных попыток — в `MAIL_SETUP.md`. Для отправки требуется PHP Ctype, для защищенного SMTP также OpenSSL.

Сессии администратора хранятся в базе. Сервер не завершает их по неактивности или возрасту, а cookie продлевается при посещении панели. Вход сохраняется после закрытия браузера и перезапуска PHP. Очистка cookies, явный выход, изменение пароля или удаление cookies самим браузером потребуют повторного входа.

## Фотографии и конфиденциальность

Файлы хранятся в выбранной приватной папке данных. Публичные фотографии моделей выдаются через `/media/public/…`. Фотографии и документы кандидатов доступны только после входа администратора.

Один файл — до 5 МБ; в заявке кандидата — до трех файлов. Для анкет моделей поддерживаются JPG, PNG и WebP, для вложений заявок также PDF. Проверьте в панели хостинга `upload_max_filesize` не менее 6M и `post_max_size` не менее 20M. Файл `.user.ini` содержит эти значения для PHP-FPM; если провайдер запрещает переопределение, задайте их в панели хостинга.

## Резервное копирование

Сохраните `config.php`, всю приватную папку данных и, при использовании MySQL, выгрузку базы из панели хостинга. Для SQLite сохраните приватную папку целиком, включая файлы SQLite/WAL, либо выполняйте копирование при остановленных изменениях. Для экспорта записей в JSON после входа откройте `/api/studio/export`.

`config.php` содержит рабочие реквизиты базы и хеш пароля. Эти файлы создаются только на вашем хостинге и не входят в поставляемый ZIP.

## Если нужен другой пароль

При наличии SSH можно выполнить из папки сайта:

```sh
read -r -s GRACE_NEW_ADMIN_PASSWORD
export GRACE_NEW_ADMIN_PASSWORD
php tools/reset-password.php
unset GRACE_NEW_ADMIN_PASSWORD
```

Сам пароль не передается аргументом команды и не выводится. После изменения все устройства должны войти заново.

## Если хостинг использует только Nginx

Передайте поддержке хостинга пример `nginx.example.conf`. Для Nginx без Apache нужны маршрутизация запросов на `index.php` и запрет доступа к служебным папкам. Если Nginx работает перед Apache, обычно достаточно `.htaccess`.

## Проверка после установки

Откройте главную, каталог и одну анкету. Войдите в панель, измените тестовую анкету, загрузите фотографию и отправьте тестовую заявку через сайт. Новое сообщение должно появиться в панели.

Если возникает ошибка 500, проверьте журнал ошибок PHP в панели хостинга, версию PHP и права на файлы. Если `/api/public` возвращает страницу 404, проверьте наличие `.htaccess` и поддержку `mod_rewrite`.

Данная сборка устанавливается в корень отдельного домена или поддомена. Установка в подпапку потребует изменения базовых адресов.
