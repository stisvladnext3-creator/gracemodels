# Полный архив сайта модельного агентства

В архиве находятся исходники публичного сайта и панели, все 12 исходных фотографий, готовая серверная сборка, миграции базы, автоматические проверки и снимок текущих данных сайта.

Новый адрес панели: `/s/9f27c6a40be34d58a17e6c92`. Старый адрес отключен.
Логин администратора: `gracemodels`. Пароль, который вы указали в чате, уже настроен на опубликованном сайте. Сам пароль и его рабочий хеш в архив не включены.

## Что внутри

- `public/` — страницы, стили, браузерный код и фотографии.
- `worker/` — сервер, обработка заявок, авторизация и постоянные сессии.
- `dist/server/index.js` — готовая сборка для Cloudflare Workers.
- `drizzle/` — структура базы и миграции.
- `backup/data.json` и `backup/restore-data.sql` — модели, новости, настройки, заявки и последние записи истории изменений на момент выгрузки.
- `backup/uploads/` и `backup/upload-manifest.json` — загруженные через панель файлы, если они были на момент выгрузки.
- `tests/` — проверки доступа, входа, заявок и работы каталога.

Сессии устройств, ограничения попыток входа и служебные ключи размещения в архив не переносятся. После переноса на другой сервер нужно войти заново.

## Проверить исходники

Требуется Node.js 24 или новее. Устанавливать библиотеки для сборки не нужно.

```sh
npm test
npm run build
```

Это сайт с сервером и базой, поэтому для полноценной работы недостаточно открыть HTML двойным щелчком. Импорт в Mobirise не предусмотрен: редактирование выполняется в собственной панели.

## Разместить на своем аккаунте Cloudflare

Файл `.openai/hosting.json` относится к текущему размещению в Sites. Для независимого размещения используется пример `wrangler.example.jsonc`.

1. Выполните `npx wrangler login` в своей учетной записи Cloudflare.
2. Создайте базу командой `npx wrangler d1 create grace-models` и хранилище `npx wrangler r2 bucket create grace-models-media`.
3. Скопируйте `wrangler.example.jsonc` в `wrangler.jsonc`. Вставьте реальный ID созданной базы. При необходимости измените имена сайта и хранилища.
4. Примените схему и восстановите данные в новую пустую базу:

```sh
npx wrangler d1 migrations apply DB --remote --config wrangler.jsonc
npx wrangler d1 execute DB --remote --config wrangler.jsonc --file backup/restore-data.sql
```

5. Если в манифесте выгруженных файлов есть записи, восстановите их:

```sh
node scripts/restore-uploads.mjs grace-models-media
```

6. Соберите и разместите сайт:

```sh
npm run build
npx wrangler deploy --config wrangler.jsonc
```

7. Задайте пароль администратора. Можно использовать пароль, который вы указали в чате. Команда вводит его скрыто и передает на сервер только хеш:

```sh
node scripts/set-admin-password.mjs
```

После этого откройте адрес своего сайта с окончанием `/s/9f27c6a40be34d58a17e6c92` и войдите с логином `gracemodels`.

Сессия сохраняется после закрытия браузера и продлевается при посещении панели. Сервер не завершает ее по возрасту или неактивности. Повторный вход потребуется после явного выхода, очистки cookies, изменения пароля или при удалении cookies самим браузером.
