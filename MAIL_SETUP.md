# Grace Models — полные анкеты по почте

Новые анкеты «Стать моделью» отправляются отдельными письмами на:

- Info@grace-models.com
- gracemodelsmail@gmail.com
- gracemodelsmoscow@gmail.com
- info@grace-models.ru

Заявки на бронирование модели отправляются на gracemodelsmoscow@gmail.com и info@grace-models.ru.

В письме находятся все заполненные поля: контакты, возраст, город, Телеграм, параметры, цвет волос и глаз, ссылка на файлообменник, сообщение, дополнительные вопросы из редактора формы и отметка согласия. Для возраста 14–17 лет передается также текст и дата дополнительной отметки. Для букинга — контакты, компания, выбранная модель, дата съёмки и описание проекта. Загруженные фотографии приложены к письму оригинальными файлами. Также есть ссылка на заявку в защищенном кабинете. Ответ на письмо адресуется отправителю анкеты.

## Отправка через почту хостинга

По умолчанию используется стандартная функция PHP `mail()` на NIC.ru. Внешние сервисы и Composer для работы сайта не требуются. Отправитель по умолчанию — `no-reply@grace-models.ru`; его можно изменить в серверном `config.php`:

```php
'mail' => [
    'transport' => 'mail',
    'from_email' => 'no-reply@grace-models.ru',
],
```

Это элемент существующего массива конфигурации, рядом с `site_url` и `database`. Остальные значения сохраняются. Для почты требуется расширение PHP Ctype.

После загрузки обновления отправьте одну настоящую тестовую заявку через сайт и проверьте прием на своих адресах, включая папку спама. Локальные проверки архива используют тестовые почтовые серверы и не отправляют письма на ваши реальные ящики.

## SMTP

Если почта хостинга отключена или нужен почтовый ящик с авторизацией, укажите в `config.php` реквизиты SMTP из панели почтового сервиса:

```php
'mail' => [
    'transport' => 'smtp',
    'host' => 'smtp.example.ru',
    'port' => 465,
    'encryption' => 'ssl',
    'username' => 'АДРЕС_ВАШЕГО_ПОЧТОВОГО_ЯЩИКА',
    'password' => 'ПАРОЛЬ_ПОЧТОВОГО_ЯЩИКА',
    'from_email' => 'АДРЕС_ВАШЕГО_ПОЧТОВОГО_ЯЩИКА',
],
```

`smtp.example.ru` — пример: используйте адрес, выданный вашим почтовым сервисом. Для порта 587 обычно применяется `encryption => 'tls'`, для 465 — `ssl`; сверяйтесь с настройками сервиса. Для защищенного SMTP требуется PHP OpenSSL. Проверка сертификата сервера включена.

Рабочий пароль вводится только в приватный `config.php` на хостинге. Его не нужно отправлять в чат или добавлять в GitHub. Эта конфигурация не попадает в публичный API сайта и резервный JSON-экспорт кабинета.

## Статус и повторная отправка

Заявка сначала сохраняется в базе вместе с очередью писем. Первую попытку сайт выполняет автоматически. Ошибка почтового сервера не отменяет принятую заявку.

В кабинете откройте заявку → «Отправка полной анкеты по почте». Для каждого получателя показан статус. «Передано почтовому серверу» означает, что почта хостинга или SMTP приняла письмо; конечное получение проверяется в самом ящике.

При временном сбое доступны автоматические повторные попытки и кнопка «Повторить неотправленные письма». Письма, уже принятые сервером, эта кнопка повторно не отправляет. Старые заявки, полученные до установки рассылки, автоматически не рассылаются.

Для повторных попыток независимо от посещений сайта добавьте в планировщик NIC.ru запуск раз в минуту:

```text
ПУТЬ_К_PHP_8.1_ИЛИ_НОВЕЕ /ПОЛНЫЙ/ПУТЬ/К/САЙТУ/tools/send-notifications.php 20
```

Используйте реальные пути из панели хостинга. Скрипт запускается через CLI; открытие его в браузере закрыто. Без планировщика первая отправка работает сразу, а повторные попытки выполняются также при открытии кабинета. После пяти неудачных попыток письмо можно повторно отправить кнопкой после исправления настроек.
