# Grace Models — документы в кабинете

В кабинете есть раздел «Документы» с двумя независимыми редакторами:

- «Согласие на обработку персональных данных» — открывается по `/consent`, связано с обязательной отметкой в формах;
- «Политика конфиденциальности» — отдельная страница `/privacy` и отдельная ссылка в футере.

Для каждого документа можно изменить заголовок и полный текст, затем нажать «Сохранить и опубликовать». Текст появляется на сайте сразу. Обратите внимание на реквизиты, сроки и описание фактического порядка работы агентства при подготовке своей редакции.

Абзацы разделяются пустой строкой. Заголовок раздела можно начать с `##`, пункт списка — с `-`, выделение — с `**текст**`. HTML отображается как обычный текст и не выполняется в браузере.

Предыдущее согласие перенесено из версии сайта 2.2.1 с сохранением редакции `2026-11-21.1`. Для новой страницы политики подготовлен исходный текст по предоставленным реквизитам и функциям сайта, включая формы и отправку полных анкет в служебную почту. Оба текста доступны для изменения в кабинете.

Каждое сохранение создает отдельную редакцию. Предыдущие опубликованные версии сохраняются и доступны через «Историю редакций». В заявке записывается редакция согласия, которую подтвердил отправитель; изменение документа не меняет прежние подтверждения. Для известных сохраненных редакций в заявке есть ссылка на соответствующий текст.

Если согласие изменилось во время заполнения формы, сайт попросит посетителя ознакомиться с актуальным текстом и подтвердить его повторно. Заполненные поля и выбранные файлы остаются в форме.

При редактировании из двух окон сайт проверяет исходную редакцию и не дает случайно затереть более свежие правки. Текст несохраненной формы остается в редакторе при ошибке.

Резервная выгрузка JSON включает действующие документы и полные тексты предыдущих редакций. Для полной резервной копии также сохраняйте базу из панели хостинга.
