# Grace Models — обновление 2.5.2

## Установка на NIC.ru

1. Сохраните резервную копию файлов и базы сайта в панели хостинга.
2. Распакуйте содержимое `grace-models-php-update-v2.5.2.zip` в папку установленного сайта с заменой файлов и сохранением путей. Это папка с `config.php`, `index.php` и `app`.
3. Перезагрузите страницу кабинета: Ctrl+F5 или Cmd+Shift+R.

Обновление включает предыдущие правки и подходит для установленных PHP-версий 2.0–2.5.1. Повторная установка и ручной импорт SQL не нужны. Рабочие `config.php`, база и пользовательские фотографии в архив не входят.

## Получатели

Для заявки «Стать моделью» используются все четыре адреса:

- Info@grace-models.com
- info@grace-models.ru

- gracemodelsmoscow@gmail.com

Для букинга используется только **gracemodelsmoscow@gmail.com**.

Изменение публичной почты в общих настройках сайта не изменяет этот список.

## Что изменилось в отправке

Раньше сайт последовательно передавал отдельное письмо для каждого адреса. Теперь одна полная анкета с фотографиями передается на почтовый сервер сразу для всех ожидающих получателей. Это уменьшает число операций с почтовым сервисом и повторную передачу вложений.

Сохраняется отдельный статус для каждого получателя. При частичном отказе SMTP адреса, принятые сервером, отмечаются отдельно от отклоненных. Повторная попытка касается только оставшихся получателей. Фоновая обработка продолжает работу при закрытии вкладки посетителем в пределах ограничений PHP и хостинга.

По умолчанию отправителем является существующий ящик `info@grace-models.ru`. Для SMTP без явно заданного отправителя используется адрес авторизации. Явный `from_email` в приватном `config.php` сохраняет приоритет; укажите там действующий и разрешенный почтовым сервисом ящик.

## Дослать ранее полученную анкету

Откройте кабинет → «Заявки» → нужную анкету → «Отправка полной анкеты по почте».

Проверьте все четыре получателя. «Не поставлено в очередь» означает, что для этого адреса нет записи об отправке. Нажмите **«Повторить неотправленные письма»**, чтобы восстановить недостающих получателей и повторить неудачные отправки выбранной анкеты. Письма со статусом «Передано почтовому серверу» не дублируются. Одновременное нажатие из двух окон не создает повторных записей.

Установка обновления и просмотр заявок не рассылают старые анкеты автоматически. Неотправленные копии букинга на адреса, исключенные из текущего списка, отменяются при обработке очереди. История уже переданных писем сохраняется.

## Проверить получение

После загрузки отправьте одну тестовую анкету и проверьте статусы четырех адресов в кабинете и получение в самих ящиках. Для букинга должна создаваться одна отправка.

Статус «Передано почтовому серверу» подтверждает прием письма почтовым сервисом, а не попадание во «Входящие». Если при этом письма не видны, проверьте спам и журнал доставки NIC.ru либо настройте SMTP с авторизацией по `MAIL_SETUP.md`. Пароль почты хранится только в приватном `config.php` на хостинге.

Для повторных попыток независимо от посещений кабинета остается доступен планировщик NIC.ru со скриптом `tools/send-notifications.php`.
